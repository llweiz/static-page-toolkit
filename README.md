# static-page-toolkit
本地离线静态网页工具箱，全部原生HTML+JavaScript，无框架依赖，无需联网。
开源协议：MIT

## 内置工具
1. text-convert.html：文本处理工具
   - 大小写转换、去除空行、去除首尾空格、URL编解码
2. timestamp-calc.html：时间戳工具
   - 时间戳 ↔ 日期互相转换、计算时间间隔

## 使用方式
直接双击html文件，使用浏览器打开即可，不需要部署服务。

## 特点
1. 所有运算在本地浏览器执行，数据不会上传网络
2. 无外部资源依赖，断网可用
3. 代码完全原创，无复制第三方项目，可自由二次改造
